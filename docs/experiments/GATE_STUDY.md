# Gate 与优化步数对照

本轮固定 seed 42、2M target tokens、相同训练顺序和语料。将 micro-batch=2、accumulation=8 改为 micro-batch=2、accumulation=2。对照包含 L，以及 R/G 各 alpha_init=0.001、0.01、0.05，共七组。adapter 学习率仍为 1e-4，LoRA 为 2e-5，5% token warmup 后 cosine decay。它检验初始化和更多更新次数；不能单独回答增加训练 token 的作用。

每十步采样最后一个 micro-batch 的 gate、注入比例和梯度。梯度范数记录在全局裁剪之后；激活统计发生于该次更新之前。额外诊断在固定前 100,000 验证 target tokens 上做同 checkpoint memory-on/off 配对。命中由预测位置 t 的 key 决定，对应标签 t+1。激活摘要是文档统计的均值，非全语料 token 加权分位数。

## 旧 G checkpoint 的实测

- gate 平均 0.80394，文档 gate 中位数的均值 0.91181。
- 注入前计算的 delta/h 范数比均值 1.3606%；BF16 相加后的实际变化为 1.3664%。
- 相加后约 14.85% 的命中位置向量分量未变化，不能解释为整个分支消失。
- 26,213 个命中预测位置：on loss 2.9754843，off loss 2.9756610。
- 73,787 个未命中预测位置：on loss 3.0003051，off loss 3.0006133。未命中位置也可能受之前注入经 attention 传播影响。

这些测量否定了“gate bias 几乎不动，因此 gate 没打开”的推断。此前用 sigmoid(bias) 估计真实 gate、用 alpha 单独估计注入比例都不充分。此前关于梯度不足的判断也是待验证假说，AdamW 的自适应缩放使原始梯度缩小不等价于参数更新同比缩小。

旧 G 的 C-Eval memory-off accuracy 为 51.0401%，宏平均 49.8082%；memory-on 分别为 50.5201%、49.2719%。On−off 宏平均差 -0.5363 pp，95% 配对 bootstrap 区间 [-1.1722, 0.03993] pp；开启 memory 改对 5 题、改错 12 题。区间仍跨 0，不宜宣称显著退化。

运行入口：scripts/run_gate_study.sh。结果目录：服务器 runs/gate_study，日志目录 logs/gate_study。先运行原 G 的 memory-off C-Eval，再并行七组训练、C-Eval 和 on/off loss 诊断。

全部完成 2,000,000 target tokens、747 次参数更新（旧实验为 187 次）。

区间基于每组 10,000 次按学科配对重采样；未作多重比较校正，也不包含训练 seed 方差。全部跨 0。C-Eval val 用于探索配置，不能把挑出的最好结果视作独立测试结论。C-Eval test/CMMLU test 本轮未使用。

这轮没有发现教师表相对随机表的稳定优势。增加更新次数使各组完整验证 loss 较旧实验略低，但该变化也同时改变了有效 batch 和梯度噪声，不能单独归因为更新次数。提高 alpha 没有带来单调的 C-Eval 收益。

固定 100k 验证 token 的 G 分支实测：

| alpha 初值 | gate 均值 | BF16 后实际注入/h | 命中 loss：on−off | 未命中 loss：on−off |
|---|---:|---:|---:|---:|
| 0.001 | 0.3814 | 1.0369% | -0.000277 | +0.000082 |
| 0.01 | 0.1595 | 0.9643% | -0.000062 | -0.000045 |
| 0.05 | 0.0862 | 1.3781% | -0.000421 | -0.000505 |

较大的 alpha 初值最终对应更小的 gate，实际注入收敛到约 1% 量级。它显示 gate 会补偿缩放参数，不能将 alpha 与注入强度直接等同。0.05 的 loss 改善更明显，但并未使 C-Eval 优于 L 或随机表。

仍不能据此断言增加训练总 token 无效：当前各组仍只训练 2M tokens。若下一步专门检验训练量，应固定 alpha=0.001 和新 batch 配置，从头设定 10M-token 学习率日程，对 L/R/G 同预算训练，保留 2M/5M/10M checkpoint。不能把已经衰减到零的 2M 日程直接当作原样延长。现有 resume 会拒绝预算清单不一致，防止静默改变实验。
